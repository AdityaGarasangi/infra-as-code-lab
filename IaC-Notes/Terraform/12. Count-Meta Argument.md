The `count` meta-argument is used to **create multiple instances of the same resource or module** using a single block of configuration.

Instead of writing the same resource multiple times, `count` allows Terraform to **loop and create duplicates automatically**.

---

- `count` takes a **number value** that determines how many instances Terraform should create.

Example:

```
resource "aws_instance" "web" {
  count         = 3
  ami           = "ami-123456"
  instance_type = "t3.micro"
}
```

Terraform will create:

```
aws_instance.web[0]
aws_instance.web[1]
aws_instance.web[2]
```

So **3 EC2 instances** will be created.

---

- Each resource created with `count` gets an **index number**, starting from `0`.

This index can be accessed using:

```
count.index
```

Example:

```
resource "aws_instance" "web" {
  count         = 3
  ami           = "ami-123456"
  instance_type = "t3.micro"

  tags = {
    Name = "web-${count.index}"
  }
}
```

Resulting instance names:

```
web-0
web-1
web-2
```

---

- `count` is commonly used with **variables** so that the number of resources can be controlled dynamically.

Example:

```
variable "instance_count" {
  type    = number
  default = 2
}
```

Usage:

```
resource "aws_instance" "web" {
  count         = var.instance_count
  ami           = "ami-123456"
  instance_type = "t3.micro"
}
```

If:

```
instance_count = 2
```

Terraform creates **2 instances**.

---

- `count` can also be used for **conditional resource creation**.

Example:

```
variable "create_instance" {
  type    = bool
  default = true
}
```

Resource:

```
resource "aws_instance" "web" {
  count = var.create_instance ? 1 : 0

  ami           = "ami-123456"
  instance_type = "t3.micro"
}
```

If:

```
create_instance = true
```

Terraform creates **1 instance**.

If:

```
create_instance = false
```

Terraform creates **0 instances**.

---

- Resources created with `count` must be referenced using **index notation**.

Example:

```
aws_instance.web[0].id
```

If used in outputs:

```
output "instance_ids" {
  value = aws_instance.web[*].id
}
```

This returns **all instance IDs**.

---

- `count` can also be used with **lists to iterate over values**.

Example:

```
variable "subnet_ids" {
  type = list(string)
}
```

Resource:

```
resource "aws_instance" "web" {
  count = length(var.subnet_ids)

  subnet_id = var.subnet_ids[count.index]
}
```

Terraform will create **one instance per subnet**.

---

- One limitation of `count` is that it **relies on numeric indexes**. If the order of values changes, Terraform may **destroy and recreate resources unexpectedly**.

Example problem:

```
old list: ["subnet-a","subnet-b"]
new list: ["subnet-b","subnet-a"]
```

Terraform may think resources changed and **replace them**.

Because of this, Terraform often recommends using **`for_each` instead of `count`** when working with collections of unique values.

|Feature|Description|
|---|---|
|`count`|Creates multiple copies of a resource|
|`count.index`|Index number of the resource instance|
|`count = var.number`|Dynamic resource creation|
|Conditional count|`count = condition ? 1 : 0`|
|Resource reference|`resource_name[index]`|
