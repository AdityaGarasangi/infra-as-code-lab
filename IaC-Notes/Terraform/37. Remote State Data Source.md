 
## What is Remote State Data Source?

The **Remote State Data Source** allows a Terraform configuration to **read outputs from another Terraform state file**.

This is useful when **multiple Terraform projects need to share infrastructure information**.

Example:  
A **VPC Terraform project** can expose outputs that another project (like **EC2 deployment**) can use.

---

# Why It Is Used

Remote state helps when infrastructure is **split into multiple Terraform configurations**.

Example architecture:

|Project|Infrastructure|
|---|---|
|network|VPC, Subnets|
|compute|EC2 instances|
|database|RDS|

The **compute project can read VPC outputs from the network project**.

---

# Basic Syntax

data "terraform_remote_state" "network" {  
  backend = "s3"  
  
  config = {  
    bucket = "terraform-state-bucket"  
    key    = "network/terraform.tfstate"  
    region = "us-east-1"  
  }  
}

This loads the **remote state from the S3 backend**.

---

# Accessing Remote Outputs

If the network project has:

output "vpc_id" {  
  value = aws_vpc.main.id  
}

You can access it like:

data.terraform_remote_state.network.outputs.vpc_id

Example usage:

resource "aws_instance" "app" {  
  subnet_id = data.terraform_remote_state.network.outputs.subnet_id  
}

---

# Example Architecture

network-project  
 ├── VPC  
 ├── Subnets  
 └── outputs.tf (vpc_id, subnet_id)  
  
compute-project  
 └── reads remote state to deploy EC2

This allows **modular infrastructure design**.

---

# Supported Backends

Remote state works with backends like:

|Backend|Supported|
|---|---|
|S3|Yes|
|Terraform Cloud|Yes|
|Azure Storage|Yes|
|GCS|Yes|

---

# Important Points

- Only **outputs from the remote state** can be accessed.
- Remote state must already **exist before reading it**.
- Useful for **multi-project infrastructure setups**.
- Helps maintain **modular Terraform architecture**.

---

# Quick Summary

|Feature|Description|
|---|---|
|Purpose|Access outputs from another Terraform state|
|Used With|Multi-project infrastructure|
|Access Syntax|`data.terraform_remote_state.<name>.outputs.<value>`|
|Requirement|Remote state must exist|

Remote state data sources enable **sharing infrastructure data between separate Terraform configurations**.
