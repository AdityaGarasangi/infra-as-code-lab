## What is a `moved` Block?

A **`moved` block** is used to tell Terraform that a **resource address has changed**.

It helps Terraform **track renamed or relocated resources** without destroying and recreating them.

This is useful during **refactoring Terraform code**.

---

## Basic Syntax

moved {  
  from = aws_instance.old_name  
  to   = aws_instance.new_name  
}

---

## Example

Before refactoring:

resource "aws_instance" "web" {  
  ami           = "ami-123456"  
  instance_type = "t2.micro"  
}

After renaming the resource:

resource "aws_instance" "web_server" {  
  ami           = "ami-123456"  
  instance_type = "t2.micro"  
}  
  
moved {  
  from = aws_instance.web  
  to   = aws_instance.web_server  
}

Terraform understands that **the resource was renamed**, so it **updates the state instead of recreating the resource**.

---

## When to Use

Use `moved` blocks when:

- Renaming resources
    
- Moving resources between modules
    
- Changing resource structure during refactoring
    

---

## Important Points

- Prevents **unnecessary resource destruction**.
    
- Updates the **Terraform state mapping**.
    
- Only affects **state tracking**, not infrastructure itself.
    
- Can also be used for **module resource moves**.
    

Example:

moved {  
  from = aws_instance.web  
  to   = module.web.aws_instance.web  
}

---

## Quick Summary

|Feature|Description|
|---|---|
|Purpose|Track resource renaming or relocation|
|Prevents|Resource destruction and recreation|
|Used During|Terraform refactoring|
|Affects|Terraform state mapping|
