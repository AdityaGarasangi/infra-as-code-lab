- It is better to explicitly specify the provider version, as using the latest version may change the workflow and potentially break existing configurations.
- During `terraform init`, if the version is not specified, the latest available provider version will be downloaded.
- For production use, it is recommended to explicitly define the provider `version` attribute to ensure that new versions with breaking changes are not automatically installed.
- `~>` specifies Any version in 6.x.x range, But not 7.0 or more
```
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 6.0"
    }
  }
}

provider "aws" {
  region = "ap-south-1"
}
```
