
1. **Provisioning EC2**
    
    - Considerations → Available Regions | VM Configs (CPU,RAM,storage,OS)
    
    ```
    provider "aws" {
    	region = "us-east-1"
    	access_key = " "
    	secret_key = " "
    }
    
    resource "aws_instance" "firstEC2" {
    	ami = amazon.linux.id
    	instance_type = "t3.micro"
    	
    	tags = {
    		Name = "FristEC2"
    	}
    }
    ```
    
2. **Providers**
    
    - Depending on type of infra that needed to create, we can have appropriate providers
        
    - **Provider Plugins**
        
        - A provider is a plugin that lets terraform manage an external API
        - _**terraform init**_ → plugins required for providers are automatically downloaded and saved locally to **.terraform** directory
        
        ```
        provider "aws" {
        	region = "us-east-1"
        	access_key = " "
        	secret_key = " "
        }
        ```
        
    - Providers not maintained by HashiCorp, Must use **required_providers block nested** inside terraform configuration block
        
    
    ```
    <-- Not Maintained by HashiCorp -->
    terraform {
    	required_providers {
    		digitalocean = {
    			source = "digitalocean/digitalocean"
    			version = "~> 2.0"
    		}
    	}
    }
    ```
    
3. **Resource Block**
    
    - Describes one or more infra objects
    - Defines the **desired state** of a real infrastructure object
    - Is the fundamental unit of Infrastructure as Code

```

resource "aws_instance" "web" {
	ami = amazon.linux.id
	instance_type = "t3.micro"
	
	tags = {
		Name = "FristEC2"
	}
}
```

- Every resource has:
    
    - A **provider type** (what kind of object it is)
    - A **local name** (Terraform’s internal reference label)
    
    Together they form:
    
    - A unique **resource address**
    - The identity stored in state
- Declared a resource give resource type (aws_instance) with given local name (web)
