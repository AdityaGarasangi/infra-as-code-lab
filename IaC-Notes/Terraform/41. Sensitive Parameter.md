## What are Sensitive Parameters?

**Sensitive parameters** are variables, outputs, or values marked as **sensitive** so Terraform **hides them from CLI output**.

Used to protect data like:
- passwords
- API keys
- tokens

---

## Defining Sensitive Variable

```
variable "db_password" {  
  type      = string  
  sensitive = true  
}
```
---

## Example Usage

```
resource "aws_db_instance" "db" {  
  password = var.db_password  
}
```

Terraform will **not display the password** in plan/apply output.

---

## Sensitive Outputs

```
output "db_password" {  
  value     = var.db_password  
  sensitive = true  
}
```
---

## Behavior

- Value is **hidden in CLI output** (`<sensitive>`)
- Still stored in **state file**
- Accessible internally within Terraform

---

## Important Points

- Sensitive ≠ encrypted ❗
- State file may still contain secrets
- Use **remote backend + encryption** for safety
- Avoid logging sensitive values

---

## Quick Summary

|Feature|Description|
|---|---|
|Purpose|Hide sensitive data in output|
|Works On|Variables, outputs|
|CLI Output|Hidden (`<sensitive>`)|
|Stored in State|Yes|
