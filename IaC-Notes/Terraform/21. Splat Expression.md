- **Splat expressions provide a concise way to extract attributes from multiple resources or objects at once.**
- They are mainly used when a resource is created using **`count` or `for_each`**, and you want to **collect a specific attribute from all instances**.

Instead of manually referencing each resource like this:

```
aws_instance.web[0].id
aws_instance.web[1].id
aws_instance.web[2].id
```

A **splat expression** allows you to get them all at once.

---

- Basic syntax:

```
resource_type.resource_name[*].attribute
```

Example:

```
aws_instance.web[*].id
```

This returns a **list of all instance IDs**.

---

### Example 1 — Using `count`

Resource:

```
resource "aws_instance" "web" {
  count         = 3
  ami           = "ami-123"
  instance_type = "t3.micro"
}
```

Each instance has an ID:

```
aws_instance.web[0].id
aws_instance.web[1].id
aws_instance.web[2].id
```

Using splat expression:

```
aws_instance.web[*].id
```

Result:

```
[
  "i-12345",
  "i-67890",
  "i-54321"
]
```

Terraform returns **a list of values**.

---

### Example 2 — Output All Public IPs

Resource:

```
resource "aws_instance" "web" {
  count         = 3
  ami           = "ami-123"
  instance_type = "t3.micro"
}
```

Output:

```
output "public_ips" {
  value = aws_instance.web[*].public_ip
}
```

Result:

```
[
  "54.11.22.33",
  "18.22.33.44",
  "13.45.67.89"
]
```

This collects **all public IPs automatically**.

---

### Example 3 — Using with Lists

Splat expressions can also be used on lists of objects.

Example:

```
variable "servers" {
  default = [
    { name = "web1", port = 80 },
    { name = "web2", port = 443 }
  ]
}
```

Using splat:

```
var.servers[*].name
```

Result:

```
[
  "web1",
  "web2"
]
```

---

### Full Splat vs Legacy Splat

Terraform previously used **legacy splat syntax**.

Legacy:

```
aws_instance.web.*.id
```

Modern (recommended):

```
aws_instance.web[*].id
```

Modern splat is **more flexible and consistent with Terraform expressions**.

---

### Using Splat with Nested Attributes

Example:

```
aws_instance.web[*].tags.Name
```

This collects the **Name tag from all instances**.

Result:

```
[
  "web-1",
  "web-2",
  "web-3"
]
```

---

### Common Real-World Uses

Splat expressions are often used for:

|Use Case|Example|
|---|---|
|Get all instance IDs|`aws_instance.web[*].id`|
|Get all public IPs|`aws_instance.web[*].public_ip`|
|Get subnet IDs|`aws_subnet.public[*].id`|
|Get security group IDs|`aws_security_group.web[*].id`|

---

### Example — Load Balancer Target Group

Multiple instances registered to load balancer:

```
resource "aws_instance" "web" {
  count = 3
}
```

Attach them:

```
target_id = aws_instance.web[count.index].id
```

Or output them:

```
output "instance_ids" {
  value = aws_instance.web[*].id
}
```

---

### Important Behavior

- Splat expressions **always return a list**.
- Even if only one resource exists, the result is still a **list with one element**.

Example:

```
aws_instance.web[*].id
```

Result:

```
["i-12345"]
```

---

### Difference Between Index and Splat

|Expression|Result|
|---|---|
|`aws_instance.web[0].id`|Single value|
|`aws_instance.web[*].id`|List of values|

---

### Important Points to Remember

- Used to **collect attributes from multiple resources**.
- Works with resources created using **`count` or `for_each`**.
- Syntax:

```
resource[*].attribute
```

- Always returns a **list**.
- Modern syntax uses:

```
[*]
```

instead of the old:

```
.*
```

---

### Simple Mental Model

```
Index → get one resource value
Splat → get values from all resources
```

Example:

```
aws_instance.web[0].id   → one ID
aws_instance.web[*].id   → list of all IDs
```
