- **Terraform settings are defined inside the `terraform` block and control Terraform’s behavior**, such as required versions, providers, and backend configuration.

Example:

```
terraform {
  required_version = ">= 1.5.0"

  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}
```

- `required_version` → Specifies the **minimum Terraform CLI version required** to run the configuration.
- `required_providers` → Defines the **providers Terraform should install and their versions**.

Example:

```
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}
```

This tells Terraform to **download the AWS provider from the HashiCorp registry**.

- The `terraform` block is also used to configure the **backend**, which determines **where Terraform state is stored**.

Example:

```
terraform {
  backend "s3" {
    bucket = "terraform-state-bucket"
    key    = "prod/terraform.tfstate"
    region = "us-east-1"
  }
}
```

This stores the Terraform state in **S3 instead of locally**.

---

### Must Know Points

- Terraform settings are defined inside the **`terraform {}` block**.
- Used to configure:
    - Terraform version
    - required providers
    - backend state storage
- Usually placed at the **top of the configuration**.
- A configuration typically has **one terraform block per module**.
