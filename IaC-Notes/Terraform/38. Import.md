## What is Terraform Import?

**Terraform import** is used to bring **existing infrastructure (created outside Terraform)** into Terraform state.

This allows Terraform to **start managing already-created resources**.

---

# Why It Is Used

Use import when:

- Infrastructure was created **manually (AWS Console, CLI, etc.)**
- Migrating existing infra into **Terraform management**
- Avoiding **recreation of resources**

---

# Basic Syntax

```
terraform import <resource_address> <resource_id>
```

---

## Example

terraform import aws_instance.web i-1234567890

- `aws_instance.web` → resource in your `.tf` file
- `i-1234567890` → actual AWS instance ID

---

# Important Requirement

Before importing, you must **define the resource in code**.

```
resource "aws_instance" "web" {  
  ami           = "ami-123456"  
  instance_type = "t2.micro"  
}
```

Terraform does NOT create config automatically — only updates state.

---

# After Import

Run:

```
terraform plan
```

This shows differences between:

- Imported resource
- Your Terraform configuration

👉 You must **update your code to match the real resource**.

---

# Import Workflow

1. Write resource block in `.tf`
2. Run `terraform import`
3. Run `terraform plan`
4. Adjust configuration to match actual infra
5. Apply changes if needed

---

# Import Multiple Resources

Each resource must be imported **individually**.

---

# Important Points

- Import only updates **state**, not infrastructure.
- Configuration must be **manually written**.
- Helps in **adopting Terraform for existing systems**.
- Resource IDs differ per provider (e.g., AWS, Azure).

---

# Quick Summary

|Feature|Description|
|---|---|
|Purpose|Bring existing infra into Terraform|
|Command|`terraform import`|
|Affects|State file only|
|Requirement|Resource must exist in config|

Terraform import is essential for **migrating and managing existing infrastructure using Terraform**.
