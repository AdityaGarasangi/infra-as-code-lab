## What is HCP?

**HashiCorp Cloud Platform (HCP)** is a **managed cloud platform** by HashiCorp that provides hosted versions of tools like **Terraform**, **HashiCorp Vault**, and Consul.

It allows you to **use HashiCorp tools without managing the underlying infrastructure**.

---

## Core Idea

Instead of installing and maintaining:

- Terraform servers
- Vault clusters
- Consul infrastructure

HCP provides them as **fully managed services**.

---

## Main Services

### 1. HCP Terraform (Terraform Cloud)

A managed service for running Terraform workflows.

**Key features:**

- Remote execution of `plan` and `apply`
- Built-in state management
- State locking and versioning
- Team collaboration (RBAC, audit logs)
- Policy enforcement (Sentinel)

---

### 2. HCP Vault

Managed Vault service for secure secret management.

**Key features:**

- Encrypted secret storage
- Dynamic credentials
- Access control via policies
- Secret rotation and leasing

---

### 3. HCP Consul

Managed service for networking and service discovery.

**Key features:**

- Service discovery
- Service mesh
- Secure service-to-service communication

---

## Key Features of HCP

### 1. Fully Managed

- No infrastructure setup
- No upgrades or maintenance

### 2. Remote State Management

- Secure storage
- Automatic locking
- Version history

### 3. Collaboration

- Multi-user support
- Role-based access control
- Audit logging

### 4. Security

- Encryption at rest and in transit
- Fine-grained access control
- Integration with Vault

### 5. CI/CD Integration

- GitHub, GitLab, Bitbucket integration
- Automatic runs on code changes

---

## Workflow Example

Code Push → HCP Terraform → Plan → Review → Apply → Infrastructure

---

## HCP vs Self-Managed

|Feature|HCP|Self-Managed|
|---|---|---|
|Setup|Minimal|Complex|
|Maintenance|None|Manual|
|Scaling|Automatic|Manual|
|State Management|Built-in|Custom setup|
|Control|Limited|Full control|

---

## When to Use HCP

- Team-based Terraform usage
- Need for secure remote state
- CI/CD-driven infrastructure
- Avoid managing backend infrastructure

---

## Important Points

- HCP Terraform is equivalent to Terraform Cloud
- Eliminates need for custom backends (e.g., S3 + DynamoDB)
- Suitable for production environments with teams
- Provides centralized control and governance

---

## Quick Summary

HashiCorp Cloud Platform is a **managed platform for running HashiCorp tools**, providing:

- Remote Terraform execution
- Secure state management
- Secret management with Vault
- Collaboration and governance features

It simplifies infrastructure management by removing the need to manage supporting systems.

---

## Pricing Model

HCP Terraform uses **usage-based pricing**, mainly based on:

- **Managed Resources (RUM – Resources Under Management)**
- Billed **per resource per hour**

---

## Free Tier

- Free for small teams
- Includes up to **500 managed resources**
- Includes:
    - Remote runs
    - State management
    - VCS integration

---

## Paid Plans

### 1. Essentials (Pay-as-you-go)

- Charged per **managed resource/hour**
- Example:
    - ~1000 resources ≈ **$97/month**

---

### 2. Standard / Premium (Enterprise)

- Advanced features:
    - RBAC
    - Audit logs
    - Policy enforcement
- Pricing is **custom (contact sales)**

---

## Key Concept: Managed Resource

- Any Terraform-managed resource in state
- Billing depends on **peak number of resources per hour**

---

## Quick Summary

- Free tier → up to **500 resources**
- Paid → **usage-based (per resource/hour)**
- Higher plans → **enterprise features + custom pricing**
