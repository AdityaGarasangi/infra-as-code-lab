- 2 ways to create and manage infra
    1. manually approach → Usually be avoided at enterprise level
    2. automation approach → Preferred Approach for provisioning cloud infra
- Iac is the managing and provisioning of infra through code instead of manual processes
- Org could be using AWS cloudformation or terraform
    - Cloudformation uses .**yaml →** Specific for AWS
    - Terraform uses **.tf (HCL) →** Agnostics

### Benefits of Iac

- Speed of infra management
- Low risk of human errors
- version control
- easy collaboration b/w teams

## Choosing Right Iac tools

There are various types of tools that can allow to deploy infra as code

1. Terraform
2. Cloud Formation
3. Heat
4. Anisble
5. Saltstack
6. chef, puppet etc..

## Categories of Tools

Infra as code

→ Infra orchestration/provisioning

- Terrafrom | Cloud formation

→ Configuration Management

- Anisble | Chef

### Configuration Management tools

- Primarily used to maintain desired configuration of multiple systems (inside servers) like OS, install or uninstall or configure any application data etc
    - For example - All 4 instances must have docker installed with specific version
- Here its all about configuring already created infra

## Infrastructure orchestration/provisioning

- Primarily used to create and manage infra env
    - for example - create 4 instances must have r5.xlarge type and port 22 must be open etc
- Here its all about provision/creating infra and not configuring it

## Deploying Infra with terraform

### Authentication and Authorization

- Authentication is process of verifying who a user is
- Authorization is process to verify whether a user have access to
- AWS IAM → Users → Attach policies
- Terraform needs access credentials with relevant permission to create and manage the env
- **Access credentials →** Depending on providers, type of access credentials would change

|**Providers**|**Access Credentials**|
|---|---|
|AWS|Access keys|
|GitHub|Tokens|
|K8s|Kubeconfig file|
|Digital Oceans|Tokens|

- IAM → Users → Attach Policies → Security Credentials → Generate/Copy Access Key and Secret Key
